# Kindle Local Sync — Website

The official landing page for **Kindle Local Sync**, a desktop Obsidian community plugin that brings Kindle highlights and notes into Markdown — locally, without requiring an Amazon account or cloud synchronization.

[**Live Website**](https://mykyquan.github.io/kindle-local-sync-site/) · [**Install Plugin**](https://obsidian.md/plugins?id=kindle-local-sync) · [**Plugin Repository**](https://github.com/mykyquan/kindle-local-sync)

> **Repository scope:** This repository contains only the public-facing website. The Obsidian plugin's source code, tests, releases, and technical documentation are maintained separately in [mykyquan/kindle-local-sync](https://github.com/mykyquan/kindle-local-sync).

## Overview

The website introduces Kindle Local Sync and helps visitors understand how the plugin works before installing it.
